# Suggested manuscript code-availability statement

The implementation of HeLF is available at
https://github.com/YingqiWang-HIT/HeLF. The manuscript is currently under peer review. The review-stage
repository contains the model architecture, three-stage training pipeline,
inference and evaluation code, latent fusion implementation, synthetic
functional examples, and public configurations. To protect the integrity of the
ongoing review and comply with data restrictions, selected experiment-specific
parameters, complete CFD/LES preprocessing settings, official data split
identifiers, normalization statistics, and trained checkpoints are temporarily
withheld. These materials will be disclosed in the archival repository after the
peer-review process is complete.
