# Contributing

Thank you for your interest in HeLF.

1. Create a feature branch from `main`.
2. Keep public/private configuration boundaries intact.
3. Add or update tests for behavior changes.
4. Run `pytest -q` and `ruff check .` before opening a pull request.
5. Do not submit proprietary CFD data, unpublished checkpoints, confidential
   parameter files, reviewer correspondence, or restricted third-party code.

Because the associated manuscript is under peer review, issues asking for exact
withheld parameters may be closed with a reference to `docs/RELEASE_STATUS.md`.
