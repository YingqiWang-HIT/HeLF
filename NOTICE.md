# Review-stage notice

The HeLF manuscript associated with this repository is currently under peer
review. The public code release is designed to make the method structure,
interfaces, optimization stages, and latent fusion logic inspectable and
executable without disclosing every experiment-specific detail before review is
complete.

The exact values of selected loss coefficients, normalization statistics,
the reference energy of the reliability gate, fusion timesteps, official split
manifests, CFD/LES generation settings, and official checkpoints will be
published after the peer-review process and any required data clearance.

Public values labelled `REVIEW_DEFAULT` are functional defaults. They should not
be cited as the exact settings used to produce manuscript tables or figures.
